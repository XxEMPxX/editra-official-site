Installation Guide / インストールガイド

macOS 15 or later · Apple Silicon arm64 only.
macOS 15 arm64 real-device verification is not recorded. This guide does not guarantee operation.

English

  1. Download the DMG from the official site and verify SHA-256:
    3e2f5de59ed5015f3039c15bc006e2d7f6c6759c2ce7ee05bfd141d1abf0a92
  2. Open the DMG and drag EEDT.app to Applications. The frozen DMG contains EEDT.app.
  3. Developer ID signing and Apple notarization are not available. macOS may show a warning. Use only Apple’s per-app approval flow after verifying the source and checksum; never disable Gatekeeper or SIP system-wide.
  4. If the app does not open, stop if macOS reports malware, damage, or an unverifiable checksum. Report the issue via the support contact.

日本語

  1. 公式サイトからDMGを取得し、次のSHA-256を照合してください：
    3e2f5de59ed5015f3039c15bc006e2d7f6c6759c2ce7ee05bfd141d1abf0a92
  2. DMGを開き、EEDT.appをApplicationsへドラッグします。凍結DMGにはEEDT.appが含まれます。
  3. Developer ID署名とApple公証はありません。警告が表示される場合があります。配布元とハッシュを確認した後、Appleのアプリ単位の許可手順だけを使用し、GatekeeperやSIP全体を無効化しないでください。
  4. 起動できない場合、マルウェア・破損・ハッシュ不一致の警告が出たときは中止し、問い合わせ先へ報告してください。
