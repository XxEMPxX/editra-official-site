# Editra Official Site

Static website for Editra. The initial macOS Public Beta release is being prepared; download links remain disabled until the release configuration contains a reviewed, approved public release and verified ZIP checksum.

The first planned target is macOS 15.0 or later on Apple Silicon (arm64). Windows is coming soon; Linux is planned. This site is independent of the private Editra desktop source repository. See the displayed installation guide and release notes before installing any future package.
